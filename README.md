# Customer-data-analysis
## Customer Data Analysis using Power BI

This project analyzes customer shopping behavior using Power BI to identify sales trends, customer preferences, and purchasing patterns.

### Project Objectives
- Analyze customer distribution by gender and age group.
- Compare sales quantity and revenue across customer segments.
- Identify top-performing product categories.
- Analyze payment method preferences.
- Explore relationships between customer demographics and purchasing behavior.
- Build an interactive dashboard to present key business insights.

### Tools & Technologies
- **Power BI** – Data visualization and dashboard development
- **DAX** – Calculations and measures
- **Power Query** – Data cleaning and preparation
- **CSV Dataset** – Customer shopping transaction data

### Key Insights
- Female customers contributed approximately 59.7% of total revenue.
- Clothing was the highest revenue-generating product category.
- Customers aged 40–49 generated the highest revenue among the analyzed age groups.
- Cash was the most frequently used payment method.
- The project provides insights to support data-driven business decisions.

### Project Deliverables
- Power BI interactive dashboard (`.pbix`)
- Project presentation (`.pptx`)
- Customer Data Analysis Report (`.pdf`)

### Conclusion
This project demonstrates practical skills in data analysis, data visualization, DAX calculations, and business insight generation using Power BI.
